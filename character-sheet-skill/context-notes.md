# 맥락 기록

- 2026-09-15. 사용자 승인 계획에 따라 웹앱 대신 내장 ImageGen 스킬로 구현한다. 별도 API 키나 ComfyUI는 사용하지 않는다.
- 기존 미추적 영상 파일은 사용자 작업으로 취급한다. 기존 루트 계획 문서는 수정하지 않는다.
- Python 사용은 사용자가 승인한 단순 배치와 저장에 한정한다. 기준 이미지 선택은 사용자에게 맡긴다.
- 스킬 원본은 이 폴더에서 버전 관리하고 개인 스킬 폴더에 설치한다. 생성 이미지와 테스트 임시 결과는 Git에 넣지 않는다.
- 합성은 칸당 1024×1024, 최대 내용 영역 960×960에 비율 유지하여 배치한다. 개별 PNG는 바이트 그대로 복사한다. 합성 크기는 모델의 생성 해상도를 뜻하지 않는다.
- 샌드박스에서 tempfile 디렉터리 접근 거부가 재현됐다. 정상 권한 테스트에서 4개 모두 통과했다. 번들 Python의 PyYAML 부재로 검증에는 기존 ComfyUI Python을 사용했다. 생성 엔진과는 무관하다.
- 내장 ImageGen 실 호출로 TEST_001 기준 이미지를 생성하고 로컬에 복사했다. 사용자 선택을 비동기 질문으로 요청했다. 기본 시트와 재생성 실 검증은 선택 전이므로 대기한다.
- 후속 진행 요청으로 기준 선택 확정. 기본 4칸과 측면 재생성 1회를 실제 생성했다. v001/v002 파일 12개 디코드·크기·해시 확인 및 측면만 변경됨을 확인했다.
- 합성 결과의 tempfile 접근 권한이 Windows 미리보기를 막아, 저장 단계를 부모 폴더 권한을 상속하는 고유 폴더로 변경한다. 기존 버전은 보존하고 새 버전으로 재열기를 확인한다.
- 수정 후 v003을 저장하고 샌드박스에서 6개 이미지 및 manifest 재열기 성공. 합성 시트 직접 미리보기 성공. 개인 스킬에도 수정본 설치 및 해시 일치 확인. 실제 인물 사진 및 다른 스타일 검증은 범위 밖으로 남긴다.
