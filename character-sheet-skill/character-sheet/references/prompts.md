# 유형별 생성 지시

스타일 선택은 실사(기본), 애니메이션, 카툰, 클레이, 픽셀 아트, 수채화. 스타일 변경은 새로운 기준 이미지와 사용자 선택부터 시작한다.

| 유형 | 항목 순서 | 구도 |
|---|---|---|
| basic | 얼굴 정면 확대, 전신 정면, 전신 왼쪽 측면, 전신 후면 | 얼굴 1칸과 전신 3칸 |
| expressions | 중립, 미소, 크게 웃음, 슬픔, 분노, 놀람 | 동일 크기의 얼굴 정면 |
| poses | 서기, 걷기, 달리기, 앉기, 손 흔들기, 팔짱 | 전신, 인물 한 명 |
| outfits | 원본, 캐주얼, 정장, 스포츠웨어 | 정면 전신, 동일 자세 |

항목별 설명은 사용자의 수정 요청을 반영한다. 의상 설명이 없으면 캐주얼은 무지 상의와 청바지, 정장은 단정한 재킷과 바지, 스포츠웨어는 운동 상하의와 운동화를 기본으로 한다. 원본 의상은 기준 이미지 그대로 유지한다.

## 기준 이미지

사용자 설명을 보존하여 한 명의 캐릭터 기준 이미지를 생성한다. 흰색 배경, 고른 조명, 중립 표정, 얼굴 식별이 가능하고 신발까지 보이는 정면 전신. 사용자가 명시하지 않은 설정이나 배경 이야기를 추가하지 않는다. 스타일과 주요 외형 특징을 짧게 기록하고 선택을 기다린다.

## 개별 칸 공통 템플릿

```text
목적: 영상 제작을 위한 한 캐릭터의 [유형] 기준 이미지.
입력 역할: 이미지 1은 사용자가 선택한 기준 캐릭터. 이미지 2 이후는 [역할].
그림 스타일: [스타일].
이번 칸: [항목 설명]. 합성 시트가 아닌 한 장의 개별 이미지.
유지: 동일한 얼굴 구조, 헤어스타일과 색, 체형, 주요 식별 특징 [구체적 특징].
의상: [유지할 원본 특징 또는 요청된 의상 변형].
구도: [얼굴 확대/정면 전신/왼쪽 측면/후면/포즈]. 한 명만 등장.
배경과 조명: 흰색 단색 배경, 고른 스튜디오 조명.
전신일 경우 머리와 신발까지 모두 보이고 충분한 여백. 글자, 표, 테두리 없음.
```

후면에서 얼굴이 보이도록 요구하지 않는다. 픽셀 아트의 인물 유지 여부는 픽셀 스타일 안에서 판단한다. 생성 결과를 다른 스타일의 실사 정확도 기준으로 평가하지 않는다.

## 한 칸 수정

기준 캐릭터와 수정 대상 이미지를 명확히 구분한다. 사용자 요청 [변경 내용]만 바꾸고 [보존 특징]은 유지한다. 다른 칸은 다시 생성하지 않는다. 실패 결과가 있으면 무엇이 잘못되었는지 구체적으로 추가하되 원래 지시를 누적해서 모순되게 만들지 않는다.
