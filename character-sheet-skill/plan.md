# 캐릭터 시트 스킬 구현 계획

내장 ImageGen으로 기준 캐릭터와 개별 칸을 생성하고 Python/Pillow로만 비율 유지 합성을 한다. 개인 스킬로 설치한다.

1. 스킬 지침과 유형별 프롬프트를 작성한다.
2. 버전별 개별 PNG, 합성 PNG, 설정 및 참조를 보존하는 합성 도구를 구현한다.
3. 4칸·6칸, 종횡비, 원본 보존, 덮어쓰기 방지를 검증한다.
4. 기준 이미지 생성 후 사용자 선택을 받아 실제 시트·재생성 검증을 이어간다.

기본 외형/의상은 2×2, 표정/포즈는 3×2. 실사 기본 및 여섯 스타일. 외부 API 자동 전환 없음.
