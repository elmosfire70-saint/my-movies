# 로컬 턴어라운드 워크플로 계획

## 2026-09-27 착용 위치 재검증

얼굴 원본의 노출된 이마·헤어라인 보존 지시와 낮은 모자 착용 지시의 충돌을 제거한다. 공유 외형 지시에서 측면 전용 구도 문장을 분리한다. 먼저 정면만 실제 생성해 눈썹 접촉을 확인한 뒤 시트를 생성하고 기존 결과를 보존한다.

전신 프롬프트만으로는 간격이 남아 선택형 베레모 보정 단계를 추가한다. 기본 512×1152 정면의 머리를 확대해 한 번 편집하고 눈·코·입을 제외하는 마스크로 원본에 합성한다. 크롭·마스크는 이 기본 구도용이며 다른 인물 위치에는 조정이 필요하다. 같은 입력에 보정을 반복하면 질감이 손상되어 한 번만 적용한다.

## 베레모와 일반 모자의 착용 지시 분리

의상 참조에 모자가 있을 때 종류를 먼저 구분한다. 부드럽고 한쪽으로 기운 베레모는 낮게 내려온 쪽 띠가 한쪽 눈썹에 자연스럽게 닿고 반대쪽 눈썹은 보이게 한다. 일반 모자는 챙·띠를 양쪽 눈썹 가까이에 두되 눈썹을 가리지 않는다. 모자가 없으면 임의로 추가하지 않는다. 정면에서 결정한 형태·높이를 측면과 후면에 이어지게 하고, 기존 두 입력 참조로 실제 베레모 시트를 새 버전에 생성해 검토한 뒤 ComfyUI 저장본을 갱신한다.

## 베레모 착용 위치와 시점 일관성 개선

현재 두 입력 기본 그래프는 얼굴 원본을 인물 정체성으로, 의상 원본을 복장으로 사용하지만 베레모 띠가 눈썹보다 높게 뜬 결과가 있다. 정면 생성 지시에서 얼굴·의상 참조 역할, 모자 재질·형태·문양과 얼굴에 맞는 착용 높이, 옷의 앞뒤 위치를 구체화한다. 측면·후면에서는 정면에서 정한 모자 크기·기울기·띠 높이를 3차원 회전 관점에서 유지하도록 지시한다. 기존 결과를 덮어쓰지 않고 두 입력으로 전체 시트를 재생성해 모자와 복장의 일관성을 육안 검토한 다음 ComfyUI 저장본을 갱신한다.

## 두 사진만 입력하는 기본 워크플로

사용자의 기본 입력은 얼굴 원본과 의상 원본 두 장이다. ComfyUI에 저장된 `character-sheet`를 두 입력만 받는 단일 그래프로 바꾼다. 그래프 안에서 정면 전신을 먼저 생성하고, 그 결과를 측면·후면 참조와 얼굴 확대 크롭에 연결해 시트를 완성한다. 검증된 후면 전용 지시는 유지한다. 기존의 정면 선택용 1·2단계 워크플로는 별도 고급 경로로 보존한다. 새 기본 그래프의 두 LoadImage 역할, 연결, 실제 생성 결과를 확인한 뒤 ComfyUI의 `character-sheet`를 교체한다.

## 후면 앞장식 복제 수정

기존 후면 분기는 정면·측면과 같은 `complete clothing, colors, accessories ... exactly` 지시를 사용하고 정면 의상 사진도 다시 참조한다. 이 때문에 앞가슴에만 놓인 스카프 꼬리와 문양이 등 중앙에 복제됐다. 후면은 승인 정면에서 인물 체형·머리·모자·옷 종류·색·신발을 참고하되 앞면 장식의 위치를 그대로 복사하지 않도록 후면 전용 지시를 쓴다. 후면 분기에는 정면 PNG만 시각 참조로 전달한다. 기존 시트는 보존하고 후면 한 칸을 재생성한 뒤 선택 결과를 다시 합성한다.

## Qwen Image 2.1 교체

사용자가 비상업적 연구·평가 용도로 사용할 것을 확인하고 2511 FP8 Mixed 생성 모델의 삭제와 2.1로의 교체를 요청했다. 공식 INT8 ConvRot 생성 모델·인코더·전용 VAE를 설치한다. TextEncodeQwenImage21 및 참조 캐시를 사용하고, 2511 전용 flow shift와 참조 정렬 노드를 제거한다. 기존 결과는 보존한다. 새 모델 무결성 확인 뒤 지정된 구형 생성 모델만 삭제한다. 이전 인코더·VAE는 공유 여부가 미확인이므로 자동 삭제하지 않는다.

아래 2511 설계는 이전 구현 기록이다.

얼굴과 의상을 별도로 입력받아 정면 기준 캐릭터를 생성한 다음, 선택한 정면과 원본 참조로 측면·후면·클로즈업을 생성한다. 세 전신과 큰 얼굴을 수평으로 배치하고 각 원본도 저장한다.

- 모델은 ComfyUI 기본 노드에서 지원하는 Qwen Image Edit 2511 FP8 mixed를 사용한다. 최고 성능이라는 절대 순위나 얼굴 동일성을 보장하지 않는다.
- 12GB GPU에서는 메모리 오프로딩을 사용한다. 기본 20단계, CFG 4, 1장 배치. 속도보다 품질 우선이며 실제 실행 시간은 측정 전 미확정이다.
- 기준 캐릭터 선택을 위해 정면 생성과 나머지 시트 생성을 두 워크플로로 분리한다. 기존 영상 워크플로를 수정하지 않는다.
- 기본 ComfyUI 노드만 사용한다. 생성 파일과 설정은 PNG 메타데이터와 API/UI JSON으로 보존한다.
- 모델 준비, 그래프 구조 검증, 합성 검증을 하고 실제 모델 실행 여부를 별도로 기록한다.
