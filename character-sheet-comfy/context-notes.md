2026-09-22. 사용자는 RTX 3060 12GB에서 로컬 무료 모델 실행을 선택했다. 현재 서버 8188은 실행 중이며 큐는 비어 있다. 기존 설치에 Qwen 편집 모델은 없지만 기본 QwenImageEditPlus 노드는 있다. 유료 파트너 노드는 사용하지 않는다.

Carat 글의 대표 전신 이미지 → 시트 생성 흐름을 채택한다. 첨부 이미지는 배치 예시이며 얼굴·의상 원본으로 자동 사용하지 않는다. 후면의 보이지 않는 의상 디테일은 추정이다.

별도 얼굴 복원·강제 얼굴 교체·생성형 업스케일은 기본에서 제외한다. 얼굴 특징을 임의로 바꾸거나 네 시점에 추가 편차를 만들 수 있기 때문이다. 기존 프로젝트와 개인 ImageGen 스킬은 유지한다.

공식 최신 템플릿에서 flow shift 3.1, CFGNorm, index_timestep_zero 참조 정렬을 확인했다. 템플릿 설명의 20 steps / CFG 4를 기본으로 채택했다. 텍스트 인코더까지 총 30,172,239,743바이트이며 SHA256은 Hugging Face 공식 API의 LFS OID를 기록했다. 현재 시스템 RAM은 약 32GiB로 전체 모델과 다른 앱이 함께 상주하기에는 여유가 작다. 실제 속도와 메모리 안정성은 모델 실행 전에는 미확정이다.

ComfyUI 사용자 폴더에 Character_Sheet_Local을 새로 만들고 세 워크플로를 복사했다. 모델 다운로드는 별도 프로세스에서 진행 중이다. 서버를 재시작하거나 기존 실행 설정을 바꾸지 않았다. 실제 합성 검증은 색상 패널로만 수행했고 사람을 AI로 생성한 검증이 아니다.

후속 실행. 설치 프로세스가 정상 종료했고 세 파일의 SHA256 검증 성공 로그를 확인했다. 8188 서버가 모델을 인식하며 큐가 비어 있다. 기존 사용자 제공 얼굴·가운데 군인 의상으로 기본 20단계 정면 생성부터 검증한다. 선글라스는 제거하고 이전 요청의 짧은 군인 머리와 낮은 베레모 착용을 시험 지시에 반영한다. 결과와 API 요청은 output/character-sheets/COMFY_VALIDATION에 보존한다.

12:03에 ComfyUI 재시작 로그가 확인되었다. 통합 시트 작업의 마지막 수집 진행은 클로즈업 11/20이며 새 서버 큐·이력에 해당 작업이 없다. 원인 로그는 없어 메모리 오류나 사용자 재시작 중 어느 것인지 단정하지 않는다. 정면 PNG는 회수되어 보존 중이다. 이후 검증은 같은 그래프의 출력 분기를 하나씩 제출해 재시작 시 완료 결과를 재사용하도록 한다.

## 2.1 교체

사용자가 비상업적 이용을 확인하고 2511 생성 모델 삭제와 2.1 교체를 명시했다. 공식 Qwen Image 2.1 INT8 ConvRot, Qwen3-VL 8B INT8 ConvRot, 2.1 RGBA VAE를 설치하고 세 SHA256 검증이 통과했다. Qwen Research License의 비상업 연구·평가 범위를 README에 명시했다.

전용 인코더의 첫 참조가 출력 공간을 정하므로, 첫 참조에 목표 크기의 회색 캔버스를 넣고 실제 참조를 뒤에 배치했다. 참조 번호는 <imageN> 형식으로 변환했다. 25 steps / CFG 1 / Euler / simple / QwenImage21Cache auto/default를 사용한다. CFG 1에서 부정 프롬프트가 적용되지 않으므로 제외 지시도 양성 프롬프트에 포함했다. 이 캔버스 방식은 공식 템플릿 그대로가 아닌 본 작업의 레이아웃 맞춤 구성이다.

기존 배포 UI JSON은 output/character-sheets/QWEN21_VALIDATION/previous-workflows에 백업 후 교체했으며 설치 파일 해시가 소스와 일치한다. 새 모델 세 개 검증 뒤 사용자가 지정한 qwen_image_edit_2511_fp8mixed.safetensors만 삭제하고 부재를 확인했다. 구형 인코더·VAE와 기존 결과는 보존했다. 2.1 정면 실 생성 prompt_id는 f8111c90-07a3-4bea-90bb-5e1ca115e59e다.

2.1 정면 생성은 서버 시간 146.066초에 성공했다. 회수한 front-13-0.png를 육안 검토해 신발까지 포함된 한 사람의 군복 정면과 얼굴 참조 반영을 확인했다. 이는 모델 교체·전용 그래프 실제 실행 검증이며 나머지 세 시점의 품질 검증은 별도로 남는다. 초기 2511 단독 측면 작업은 이후 서버 연결 상실로 완료 확인이 안 된 채 모델 교체 요청으로 대체되었다.

생성 PNG는 RGBA이며 알파가 244~255로 약한 투명도를 포함했다. 캐릭터 시트는 불투명 배경이므로 표준 SplitImageWithAlpha의 RGB 출력을 저장·합성하도록 추가했다. 인물 RGB 픽셀은 바꾸지 않고 알파 채널만 분리한다.

후속 시트 검증. 사용자가 다음 진행을 요청해 2.1 정면 front-rgb.png와 같은 얼굴·의상 원본을 2단계 그래프에 연결한다. 세 시점 생성과 최종 합성을 실제로 실행하고 결과별 의상·시점·잘림·얼굴 일치 범위를 육안 확인한다. 기존 정면 및 실행 이력은 덮어쓰지 않는다.

2026-09-23 후속 검증. ComfyUI 재시작으로 통합 시트 job 이력은 사라졌지만 공유 출력 폴더에 남은 후면 결과를 회수했다. 나머지 측면은 단일 출력 그래프로 성공 생성했다. 개별 PNG 단위로 요청하면 중단 이후 완료 파일을 보존하기 쉽다.

Qwen Image 2.1은 close-up 프롬프트에 응답하지 않고 입력 정면의 전신을 반복했다. 실패 샘플과 별도 요청·history를 보존하고 최종 close-up에는 승인 정면을 비생성 크롭해 동일성을 보존했다. ComfyUI의 03_Assemble_Selected_Views로 네 패널을 가로 합성했다. 선택 패널과 참조, 모델·파라미터, 요청·history, 결과 해시를 MILITARY_FACE_001/v003/manifest.json에 남겼다.

후면 수정 분석. v003의 후면은 180도 뒷모습이지만 앞가슴에 걸린 빨간 스카프 꼬리와 원형 문양이 등에도 나타난다. 2단계 그래프가 후면에도 공통 `lock` 프롬프트를 적용해 장식까지 정확히 보존하라고 지시하고, 앞면 의상 사진을 중복 참조한 것이 충돌이다. 후면은 정면 PNG 하나를 형태·복장 참조로 쓰고, 앞면 전용 장식이 후면에 나타나지 않도록 별도 지시한다. 결과를 실제 생성해 확인하기 전까지 효과를 단정하지 않는다.

후면 수정 결과. 후면 전용 지시와 승인 정면 1장 참조로 재생성한 이미지에서 180도 후면·베레모·올리브 군복·검정 신발은 유지됐고, 등 중앙의 스카프 꼬리와 문양은 사라졌다. 스카프는 목 뒤 띠만 보인다. v004에서 수정 후면을 선택해 ComfyUI의 비생성 합성 그래프로 새 시트를 만들었다. 얼굴 확대는 v003과 같은 정면 기반 크롭이다. 후면의 세부 봉제선은 사진 입력에 없는 부분을 모델이 추정한다. 설치 전 워크플로는 검증 출력 폴더에 백업했다.

입력 흐름 수정 결정. `character-sheet`라는 제목으로 저장된 것은 정면 PNG를 추가로 요구하는 2단계 그래프였다. 사용자가 원하는 기본 흐름은 얼굴과 의상 사진 두 장만 입력하고 내부에서 정면을 합성·생성하는 것이다. 새 기본 그래프는 정면 생성 출력을 같은 실행의 측면·후면 참조로 연결한다. 이전 실제 생성에서 Qwen 2.1이 클로즈업 구도를 두 번 무시했으므로, 자동 경로의 얼굴 확대는 정면의 머리·상반신을 비생성 크롭한다. 크롭 영역은 기본 512×1152 정면에 맞춰져 있으며 다른 구도를 쓰면 위치를 조정해야 한다.

두 입력 워크플로 실검증. 첫 실행에서 정면·측면·후면·얼굴 확대·최종 시트가 모두 생성됐으나 의상 사진의 베레모가 정면에 반영되지 않았고 확대 컷에서 머리 윗부분이 잘렸다. 정면 프롬프트에서 의상 사진의 모자를 명시적으로 적용하고, 크롭을 기본 정면의 x136·y65·240×360으로 조정해 재실행했다. 두 번째 실행에서는 정면과 측면·후면에 베레모와 올리브 군복·검정 신발이 유지됐고 후면에는 앞가슴 스카프 꼬리가 나타나지 않았다. 얼굴 확대는 모자 전체를 포함했다. `character-sheet` 사용자 워크플로를 새 단일 그래프로 교체하고 ComfyUI API에서 두 LoadImage 노드와 저장 해시를 확인했다. 이전 사용자 워크플로는 검증 출력 폴더에 보존했다.
