# 과거 사진과 현재 사진으로 만남 영상 만들기

ComfyUI 워크플로 목록에서 `Past_Present_Meeting/00_Past_Present_Two_Photos`를 연다. 다음 두 노드에 사진을 업로드하고 실행을 누르면 시작 장면 PNG와 무음 MP4가 자동으로 저장된다.

1. **01 과거 사진 · 한 사람**에 어린 시절 또는 과거 사진을 넣는다. 한 사람의 얼굴이 선명한 사진이 좋고, 상반신·의상·배경이 함께 보이면 복원에 도움이 된다.
2. **02 현재 사진 · 같은 사람의 현재 모습**에 현재 사진을 넣는다. 정면이나 약한 측면 얼굴과 원하는 의상이 보이는 사진을 권장한다. 캐릭터 시트 대신 한 사람만 나온 사진을 사용한다.
3. 배경을 지정하려면 **03 선택 배경 사진**에 배경 이미지를 올리고 **enable · 배경 이미지 사용 ON / OFF** 노드의 스위치를 **true(켜짐)**로 바꾼다. 기본값 **false(꺼짐)**에서는 배경 사진을 추가하지 않아도 된다. 켜짐 상태에서 기본 사진을 그대로 쓰면 제공된 중립 회색 배경을 참조한다.
4. **실행**을 누른다. Qwen Image 2.1이 두 모습을 한 장면으로 합성하고, H3가 그 결과를 첫 프레임으로 받아 약 5초의 영상을 만든다. 중간 이미지를 다시 업로드할 필요가 없다.

과거 모습은 왼쪽, 현재 모습은 오른쪽에 배치한다. 배경 스위치가 꺼져 있으면 과거 사진의 배경을 사용하고, 켜져 있으면 선택 배경 사진의 장소·색·조명·원근을 우선한다. 배경 속 인물·의상·문자는 인물 참조로 사용하지 않도록 지시했다. 인물이 없는 배경 사진을 권장한다. 현재 모습이 곁에서 어깨에 손을 얹은 채 두 사람이 시선을 주고받고 미소 짓도록 지시했다. 성별·군복·해변은 고정하지 않는다. 단체 인물 사진은 사용할 사람만 잘라 넣는다. 얼굴 사진만 넣으면 보이지 않는 몸과 의상은 모델이 추정한다.

기본 입력은 이전 작업의 `child-face.jpg`와 `adult-face-new.png` 예제다. 다른 인물로 만들 때는 **두 노드 모두** 바꾼다. 장면 설명은 `배경 OFF · 과거 사진의 장소 사용` 또는 `배경 ON · 선택 배경으로 교체`에서 수정한다. enable 스위치가 해당 지시문과 배경 전달을 함께 선택한다. `02 동작·길이·해상도`에서 움직임을 수정한다. 기본 출력은 576×1024, 24fps, 약 5초다. 합성 캔버스와 영상 해상도는 함께 변경한다.

음성·대사·음악·효과음을 모두 제거한 무음 출력이다. `CreateVideo`에 오디오가 연결되지 않으며 오디오 디코딩 노드도 없다. `H3 내부 조건용 VAE`는 모델 내부 처리에 필요하므로 삭제하지 않는다. 입 모양의 변화를 완전히 막는 기능은 아니므로 표정은 조금 움직일 수 있다.

ComfyUI 출력 폴더의 `past-present/two-photo-still_*.png`와 `past-present/two-photo-video-silent_*.mp4`에 결과가 저장된다. 매번 새 번호로 저장한다. 얼굴·손·의상은 생성 과정에서 달라질 수 있으므로 최종 영상을 확인한다.

시작 장면을 먼저 검토하려면 `01_Past_Present_Still`을 사용한다. 그 PNG를 `02_Past_Present_Video`의 첫 이미지에 넣어 실행할 수도 있다. 이 단계별 방식은 시작 장면을 확정한 후 여러 동작을 시험할 때 유용하다.

검증 명령은 `python past-present-comfy/build_meeting_workflows.py`와 `python -m unittest discover -s past-present-comfy -p 'test_*.py' -v`다. 참고 쇼츠는 [과거의 자신과 만나다](https://www.youtube.com/shorts/8U6dARI1xhQ)다. 두 사진으로 한 쌍의 만남을 만든다.

동작 B enable이 true이면 어깨 토닥임, false이면 시선 교환과 미소를 사용한다. Turbo는 실제 LoRA 강도와 스텝에 연결되며 기본 true는 기존 4스텝이다. false의 20스텝 모드는 별도 영상 품질 검증 전이다. 통합 워크플로의 해상도는 ShotSettings에서 함께 제어한다. 영상 저장 경로는 codex/project/shot 접두사를 따른다. 이미지와 영상 시드는 각각 KSampler와 RandomNoise에서 변경한다.
