# 어린 시절과 성인 모습의 만남 영상

사용자가 준 성인 캐릭터 시트와 2005년 어린이 사진 세 장을 로컬 ComfyUI에 입력한다. Qwen Image 2.1로 두 사람이 같은 해변에 있는 세로 시작 장면을 만든다. 이를 MiniMax H3의 첫 프레임으로 고정해 약 5초의 자연스러운 만남 영상을 생성한다. 두 단계를 각각 편집 가능한 ComfyUI 워크플로로 저장하고, 실제 PNG와 MP4를 확인한다.

검증 기준은 한 장면에 정확히 두 인물이 등장하고, 아이 얼굴·옷과 성인 군복이 참조를 따르며, 영상에 갑작스러운 얼굴 변화나 인물 추가가 없는 것이다. 실패한 결과는 보존하고 선택 결과만 최종 폴더에 둔다.

## v003 얼굴·대사 수정

새로 첨부한 성인 초상 사진을 얼굴과 베레모의 기준으로 사용하고, 기존 캐릭터 시트는 전신 군복 기준으로 사용한다. 아이 사진과 해변 구도는 유지한다. H3의 생성 오디오를 MP4에 연결하지 않아 두 사람의 대사가 없는 영상을 만든다. 새 PNG와 MP4는 v003에 저장하고, 얼굴·두 인물의 화면 유지·무음 여부를 확인한다.
