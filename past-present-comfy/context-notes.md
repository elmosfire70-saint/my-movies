# 작업 맥락

- 참고 쇼츠는 성인과 어린 모습이 한 공간에서 만나고 성인이 아이 어깨·머리에 손을 대는 구도다. 입력 사진의 원래 배경이 해변이므로 재현 장면도 해변을 택했다.
- 성인 이미지는 사용자가 제공한 생성 캐릭터 시트이며, 어린 모습은 2005년 사진 세 장이다. 모델이 두 시점의 신원 동일성을 증명할 수 없으므로 시각적 유사성으로만 검토한다.
- Higgsfield Free 계정의 이미지 생성 호출은 Basic 요금제 요구로 거부되었다. 사용자가 로컬 ComfyUI 제작으로 방향을 바꿨다.
- 설치된 Qwen Image 2.1 INT8와 MiniMax H3 ref2va INT8 및 ComfyUI 기본 노드를 재사용한다.
- Qwen 합성 시작 장면 작업 `d501c012-3a11-4b26-9422-d44d94cba3a5`가 성공했다. 576×1024 PNG에서 정확히 두 사람이 한 공간에 있고 아이 상의, 성인 군복과 손의 접촉이 자연스럽다.
- H3 영상 작업 `4efede3a-77cd-4acf-9719-23c90a760634`을 시작 장면을 첫 프레임으로 고정해 제출했다. 별도 인물 참조를 추가하지 않아 장면 분리를 줄인다.
- 첫 MP4는 576×1024·24fps·124프레임·5.167초로 전체 디코드됐다. 첫 프레임과 중간은 적절하지만 느린 카메라 전진이 마지막에 아이를 화면 밖으로 밀어내므로 채택하지 않는다. 고정 카메라 지시로 수정해 재생성한다.
- 수정본 v002 작업 `96627a77-6ed9-4dfc-b3f9-24947e6fa5b4`가 성공했다. 첫·중간·마지막 프레임에서 두 사람이 한 화면에 남고 아이와 성인이 서로 마주 본다. 의상 문양과 얼굴 세부는 생성 결과이므로 원본과 완전히 같지 않다.
- 사용자 피드백에 따라 v003은 새로 첨부한 성인 얼굴 사진을 얼굴 기준으로 삼는다. 기존 시트는 전신 군복 기준으로 남긴다. v002의 H3 생성 오디오에 대사가 있으므로, 프롬프트만 바꾸지 않고 `CreateVideo`의 오디오 입력을 비워 최종 영상에서 대사를 제거한다.
- Qwen 작업 `66d8d833-c026-4bbe-b07a-52a23756de69`이 성공했다. 새 얼굴 사진의 눈·코·입·턱선과 베레모를 반영한 두 인물 해변 장면 PNG를 육안으로 확인하고 v003에 보존했다. 새 PNG를 H3 첫 프레임으로 지정했다.
- H3 작업 `7b4c412a-cbdd-49e7-9ecf-53b95fb9eb03`이 성공했다. v003 MP4 전체 124프레임이 디코드됐고 오디오 스트림은 0개다. 첫·중간·마지막 프레임에 아이와 성인이 모두 남으며 성인 얼굴과 베레모가 유지된다. 입 모양은 표정 때문에 바뀔 수 있지만 재생되는 대사는 없다.
