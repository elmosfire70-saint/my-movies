# 작업 맥락

- 선택 배경은 설치된 `ComfySwitchNode`를 사용한다. OFF의 미연결 on_false는 None을 반환하고, 설치된 `TextEncodeQwenImage21`은 None 이미지를 건너뛴다. ON만 배경을 인코딩한다. 기본 중립 배경 파일을 넣어 OFF에서는 별도 배경 업로드 없이 실행할 수 있게 한다.
- 첫 ON 검증에서는 중립 배경을 추가해도 바다가 남았다. 공통 조건문만으로 배경 참조를 충분히 적용하지 못해 `enable` Boolean을 이미지·문자열 스위치 양쪽에 연결하고 ON 전용 배경 교체 지시문을 사용하도록 수정했다. 이미지·문자열 스위치의 동적 UI 포트는 각각 IMAGE·STRING으로 저장하고 Boolean 연결은 BOOLEAN으로 유지한다.
- 보강한 OFF 작업 `b37a8035-6cbe-4ef2-a452-a3fcd9d1752a`와 ON 작업 `d28917bf-5b5e-42af-aeac-7efc40f880ed` 성공. 육안 확인에서 OFF는 바다·산 배경, ON은 중립 회색 배경으로 바뀌었고 두 인물이 유지된다. 검증 자료는 `output/past-present-20261004/background-option-check`에 보존한다.

- 2026-10-04 참고 쇼츠를 브라우저로 다시 확인했다. 어린 모습과 현재 모습이 나란히 있고, 현재 모습이 머리나 어깨에 손을 얹는 구도이며 여러 인물 쌍을 보여준다. 이번 입력 두 장은 한 쌍의 만남 장면에 대응한다. 참고 영상의 이름·나이 자막과 음악은 포함하지 않는다.
- 통합 워크플로는 과거·현재 사진 두 장을 입력받는다. 기존 작업에 있던 성인 시트 크롭·얼굴 별도 입력·어린 사진 세 장 의존성을 없앤다. H3 내부 조건 구성에는 오디오 VAE가 필요하지만 최종 CreateVideo에는 오디오를 연결하지 않는다.
- 통합 작업 `a19d4551-f9bc-4e31-b80c-228a41357002` 성공. 과거 `child-face.jpg`와 현재 `adult-face-new.png`만으로 시작 장면과 영상을 생성했다. 출력은 `output/past-present-20261004/v004`에 실행 요청·이력·두 입력·기존 워크플로 백업과 함께 보존한다. 124프레임 전체 디코드 및 오디오 트랙 0개를 확인했다. 대표 프레임에서 두 인물이 시선을 주고받고 마지막에 미소 짓지만, 미소 중 입이 열릴 수 있으므로 입 움직임 정지를 보장하지 않는다.

- 참고 쇼츠는 성인과 어린 모습이 한 공간에서 만나고 성인이 아이 어깨·머리에 손을 대는 구도다. 입력 사진의 원래 배경이 해변이므로 재현 장면도 해변을 택했다.
- 성인 이미지는 사용자가 제공한 생성 캐릭터 시트이며, 어린 모습은 2005년 사진 세 장이다. 모델이 두 시점의 신원 동일성을 증명할 수 없으므로 시각적 유사성으로만 검토한다.
- Higgsfield Free 계정의 이미지 생성 호출은 Basic 요금제 요구로 거부되었다. 사용자가 로컬 ComfyUI 제작으로 방향을 바꿨다.
- 설치된 Qwen Image 2.1 INT8와 MiniMax H3 ref2va INT8 및 ComfyUI 기본 노드를 재사용한다.
