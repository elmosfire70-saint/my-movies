# 범용 H3 워크플로우 사용법

ComfyUI 워크플로 목록에서 `Codex_Generic_H3`를 연다. `Codex_Generic_H3.json`은 편집 화면용이고 `.api.json`은 프로그램 제출용이다. 기본 파일은 특정 인물·사물 이미지를 포함하지 않는다. 실행 전 이미지 선택과 프롬프트 작성이 필요하다.

1. **이미지 로드**에서 원하는 참조 이미지를 선택한다.
2. **Shot Settings**에서 행동·배경·카메라·음향을 설명하고 프로젝트명, 숏명, 크기, 길이를 지정한다. 프로젝트명과 숏명은 영문·숫자·밑줄·하이픈을 사용한다.
3. **Reference Images & Roles**의 첫 줄에 첫 이미지의 역할을 적는다. 참조를 늘리려면 이미지 로드 노드를 복제해 image_2, image_3 순서로 연결하고 역할도 한 줄씩 추가한다. 인물·사물·배경·스타일·Blender 구도 참조 모두 사용할 수 있다. 한 입력에는 한 장을 연결한다.
4. 첫 숏은 **Previous Video Last Frame**의 enabled를 끈다. 다음 숏은 켜고 이전 MP4의 절대 경로를 넣는다. 마지막 프레임이 참조에 추가되고 새 영상의 첫 프레임으로 고정된다. 직접 만든 시작 이미지를 H3 Shot Inputs의 first_frame에 연결해도 된다.
5. 실행한다. 저장 위치는 현재 ComfyUI 출력 폴더 아래 `codex/프로젝트명/숏명_*.mp4`다. 저장 노드가 파일 번호를 붙인다.

`turbo` 하나로 LoRA 강도와 스텝 수가 함께 바뀐다. 켜면 4-step/강도 1, 끄면 20-step/강도 0이다. seed는 RandomNoise에서 정한다. 기존 검증 설정은 864×480, 24fps다. 길이는 H3가 허용하는 프레임 수로 올림되므로 5초 지정 시 약 5.167초가 된다.

이미지 참조는 첫 프레임을 포함해 최대 9개다. 역할에 맞는 Picture 번호는 자동 작성된다. 프롬프트에서 번호를 직접 사용할 때도 실제 연결과 일치해야 한다. 별도로 프리비즈 영상 참조 1개를 지원하며 원본 영상의 음성은 전달하지 않는다.

## Blender 프리비즈 영상 연결

`Codex · Previz Video Reference`의 enabled를 켜고 video_path에 Blender 프리비즈 MP4의 절대 경로를 입력한다. role에 카메라·타이밍·배치 중 참고할 내용을 설명한다. 출력 video_reference는 H3 Shot Inputs에 이미 연결되어 있다. 프롬프트에는 `<Video 1>` 역할 설명이 자동으로 추가된다.

max_frames는 Shot Settings의 생성 프레임 수와 연결되어 있다. 영상은 시작 부분부터 해당 길이까지만 읽으며, 짧은 영상을 생성 길이만큼 반복하지 않는다. 원본의 시간 정보를 기준으로 24fps로 변환한 후 H3 유효 길이(17k+5)로 끝부분을 자른다. max_edge는 영상 참조의 최대 변 길이이며 기본 864다. 원본보다 확대하지 않으며 가로·세로를 32의 배수로 맞출 때 비율이 조금 달라질 수 있다. preview_frames를 PreviewImage에 연결하면 실제 전달 프레임을 확인할 수 있다.

이 노드가 꺼져 있으면 기존 이미지 참조 방식으로 동작한다. 영상만 쓰려면 기본 이미지 로드와 Reference Images & Roles 사이의 연결을 제거한다. 참조 영상은 모션 참고이며 마지막 한 프레임 고정과는 다르다. 첫 프레임 고정도 함께 사용할 수 있다. 새 노드가 누락된 것으로 보이면 서버 재시작 후 Desktop에서 Ctrl+R로 화면을 갱신한다.

Blender 자동 실행·신규 AI 캐릭터 시트 제작·다중 숏 자동 편집은 이 그래프의 기능이 아니다. Blender 렌더를 이미지 로드에 연결할 수 있으며 기존 로컬 실행기는 계속 사용할 수 있다. RGB 참조는 정밀한 3D 동작을 강제하지 않는다.

소스는 `custom_nodes/codex_video_tools/__init__.py`이고 설치 위치는 ComfyUI의 `custom_nodes/codex_video_tools`다. 소스를 변경하면 설치본을 갱신하고 ComfyUI를 재시작한다. 기존 torch·numpy·PyAV와 H3 기본 노드를 사용하며 추가 모델은 필요하지 않다.
