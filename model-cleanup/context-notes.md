# 결정 기록

사용자는 정리 범위를 ComfyUI에 저장된 모든 워크플로로 지정했다. 캐릭터 시트 외 영상 워크플로도 있으므로 Qwen 2.1 파일만 남기는 방식은 사용하지 않는다. 저장된 워크플로에서 명시적으로 참조하지 않더라도 공유 경로·커스텀 노드·동적 모델 선택 가능성을 확인한 후 삭제한다.

저장된 사용자 워크플로는 default 아래 6개이며 다른 사용자 워크플로 디렉터리는 없다. `extra_model_paths.yaml`은 J:\LTX2.5를 추가한다. E: 설치 폴더 11개와 J: 5개의 실모델을 조사했으며 저장 워크플로의 모델명 8종은 모두 설치된 파일로 해결된다. 워크플로 참조가 없는 것은 H3 FL2VA 1개, 구형 Qwen 2.5 VL 인코더·구형 VAE 2개, LTX 2.5 5개다. LTX 설치 스크립트와 보고서는 남아 있지만 저장된 워크플로는 없고 설치 시각은 2026-09-13~14다. 사용자 지정 범위가 저장된 모든 워크플로이므로 해당 모델 파일은 삭제 대상이며 설치 스크립트·기록은 삭제하지 않는다. ComfyUI API 8188은 연결 거부였고 실행 중인 Python/ComfyUI 모델 프로세스는 관찰되지 않았다.

삭제 직전 동일한 8개 경로·파일 크기·저장 워크플로 미참조 여부를 재검증하고 개별 파일만 삭제했다. 삭제 파일 합계는 70,298,775,354바이트(65.47GiB)다. 전후 인벤토리와 삭제 보고서를 남겼다. 삭제 후 ComfyUI API가 다시 응답하여 큐에 작업이 없는 것을 확인했다. ComfyUI의 모델 선택 스키마에 남은 8개 파일명이 모두 있고, 캐릭터 시트 테스트 4개가 통과했다. J:의 모델 파일은 모두 삭제됐지만 폴더와 추가 모델 경로 설정, 원본 설치 스크립트·보고서는 보존했다.
