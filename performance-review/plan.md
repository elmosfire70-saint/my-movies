# 성능 검증 계획
과거·현재 인물 합성 및 무음 영상 워크플로를 대상으로 현재 하드웨어, 설치 모델, 설정, 실행 기록과 테스트를 확인한다. 공식 자료로 교체 후보를 비교한다. 기존 모델과 워크플로를 변경하지 않고 병목과 추천을 기록한다.

1. 현재 상태와 기존 측정 자료 수집.
2. 워크플로 테스트 및 서버 실행 가능성 검증.
3. 공식 모델 자료 비교 및 실측과 미검증 주장 구분.
4. 보고서와 체크리스트 완료.

## 객관 비교 후속 검토
공개 비교 자료의 하드웨어·실행 조건·샘플 수·품질 평가 방식을 확인하고, 실측 기준과 연결해 운영 적용 또는 보류를 결정한다. 모델 설치나 운영 변경은 하지 않는다.

## 노드의 프로젝트 적합성 검토
현재 상태를 유지한 채 소스와 설치된 UI JSON의 연결 의미·프롬프트를 비교한다. 기존 기능 재사용, 필요한 수정, 선택 옵션을 구분한다.
